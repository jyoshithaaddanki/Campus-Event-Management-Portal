# 🎓 Campus Event Management Portal

## 📌 Project Overview

The **Campus Event Management Portal** is a simple web-based application designed to help students discover and register for college events. The portal provides information about upcoming technical, sports, cultural, and academic events through an easy-to-use interface.

The project is developed using **HTML, CSS, and JavaScript** and can be run directly in a web browser using VS Code and Live Server. No database or Firebase is required.

## 🎯 Objective

The main objective of this project is to create a centralized platform where students can view campus events, search for events, check event details, and register for their preferred events.

## ✨ Features

* 🏠 Home section
* 📅 Upcoming events
* 🔎 Event search
* 🏷️ Event categories
* 📝 Student event registration
* 👥 Participant count
* 📢 Campus announcements
* 🌙 Dark mode
* 📱 Responsive design
* ⚡ Interactive JavaScript functions
* 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the portal
* **CSS3** – Provides styling and responsive design
* **JavaScript** – Provides event search, registration, alerts, and dark mode
* **VS Code** – Development environment
* **Live Server** – Runs the website locally

## 🚀 How to Run the Project

### Step 1: Download the Project

Download or clone this repository to your computer.

### Step 2: Open in VS Code

Open the project folder in **Visual Studio Code**.

### Step 3: Check the Files

Make sure the following files are available:

```text
index.html
style.css
script.js
README.md
```

### Step 4: Install Live Server

In VS Code:

1. Open **Extensions**
2. Search for **Live Server**
3. Install the extension

### Step 5: Run the Project

Open `index.html`.

Right-click inside the file and select:

```text
Open with Live Server
```

The Campus Event Management Portal will open in your browser.

## 📋 Main Modules

### 1. Home

Provides a welcome section and quick access to upcoming campus events.

### 2. Event Management

Displays upcoming technical, sports, cultural, and academic events with dates and locations.

### 3. Event Search

Students can search for an event by typing its name or category.

### 4. Event Registration

Students can enter their name, email address, and select an event to register.

### 5. Announcements

Displays important information and updates related to campus events.

### 6. Dark Mode

Allows users to switch between light and dark themes.

### 7. Responsive Design

The portal adjusts its layout for desktops, tablets, and mobile devices.
